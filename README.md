# NovaMind — Futuristic AI Assistant App

A multilingual AI-powered Flutter app for Android that brings multiple intelligent assistants into one clean, dark-themed interface — built for everyday users who need smart help in their own language.

## Problem
Most AI apps are English-only and built for tech-savvy users. NovaMind is built for everyday Indian users — supporting multiple languages with a simple, accessible interface anyone can use.

# 🧠 NovaMind - Your Futuristic AI Assistant

> Think Beyond. Evolve with AI. ⚡

## 📱 About NovaMind

NovaMind is a full-featured AI mobile app built with Flutter.
It works in any language and helps users with daily tasks
using the power of Artificial Intelligence.

## ✨ Features

- 🤖 **AI Chat** - Ask anything in any language
- 🎤 **Voice Input** - Speak instead of typing
- 📸 **Camera** - Take photo and ask AI
- 🌍 **Multilingual** - Hindi, English, Tamil, Telugu and more
- 🛒 **Shopping Assistant** - Smart buying advice in ₹
- 📍 **Location Tracker** - GPS tracking + Google Maps
- 📊 **Study Assistant** - Exam helper for students
- 📰 **News Assistant** - Latest news in your language
- 💰 **Finance Assistant** - Money tips for Indians
- 🍽️ **Recipe Assistant** - Cook anything with AI

## 🛠️ Tech Stack

- **Frontend:** Flutter / Dart
- **AI:** OpenRouter API (Ring-2.6-1T free model)
- **Location:** Geolocator package
- **Voice:** Speech to Text package
- **Camera:** Image Picker package
- **HTTP:** http package
